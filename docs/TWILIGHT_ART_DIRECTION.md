# マスターくまと夕暮れの部屋

**所有者の品質方針は「目指せピクサー」です。** 愛らしいシルエット、触れたくなる布、主役を引き立てる光、重さと気持ちの伝わる動きを一緒に磨きます。毛を足した、リグが動いたという技術的な達成だけで完成にせず、実際に動く画面で判断します。

2026-10-12、所有者指定の `reference/bear_master_20261012.jpg` をキャラクターのマスターに固定しました。元のDesktop画像は変更せず、内容が同一のコピーとSHA-256を `reference/manifest.json` に保存しています。部屋はDownloadsの2画像を `twilight_star_room.png`／`twilight_bear_walk.png` として保管しました。これらは参照資料で、Unityの実画面ではありません。公開再配布の権利確認は未了です。

全方向モデルシート `reference/bear_turnaround_20261012.png` を側面・背面・頭頂・足裏の補助基準に加えました。白い足裏パッド、中央の背面縫い目、背中の大きい雲、小さい尾を作ります。正面の顔は従来のマスターを優先します。

所有者の追加指摘により、寝具も画質優先の対象です。布団はBlenderの実Clothで重力とマットレス衝突から静止形を作り、ゲームには厚みを付けたメッシュを持ち込みます。これはゲーム中の布物理や、乗った際の変形を実装済みという意味ではありません。
